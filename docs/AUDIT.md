# مراجعة تأسيسية — 13 أكتوبر 2026

## ما تم إصلاحه

- توحيد كل التنسيقات في `styles/main.css` وإزالة CSS الداخلي من `index.html`.
- نقل JavaScript إلى `scripts/main.js`.
- حذف كود المعاينات التجريبي القديم وعناصره غير المستخدمة.
- إزالة الملفات السابقة `style.css` و`script.js` بعد نقل الوظائف الفعلية منهما.
- إبقاء الأصول الأصلية المعتمدة في `assets/` دون تعديل.
- إضافة `README.md` و`.gitignore` و`robots.txt` و`sitemap.xml`.
- الاحتفاظ ببيانات المشاركة Open Graph وTwitter، وإضافة أبعاد صورة المشاركة لتحسين ظهور الرابط.
- تحويل الصفحة من عرض ثلاث منصات مغلق إلى «منظومة تنمو»: عنوان موحد، خريطة للمنظومة، وبطاقة استعداد لمنصة جديدة.
- إضافة شاشة إطلاق فضائية قصيرة مع صاروخ أصلي داخل أصول المشروع، دون التأثير على محتوى الصفحة بعد انتهائها.
- تقليل كثافة وارتفاع قسم العرض، مع ضبط مستقل للموبايل للحفاظ على الإحساس السينمائي من دون إطالة أو ثقل.

## الحالة الحالية

- المشروع ثابت بالكامل ومناسب لـ GitHub Pages.
- لا توجد مكتبات JavaScript أو إطار عمل أو خادم مطلوب.
- روابط المنصات الخارجية معزولة بأمان باستخدام `noopener noreferrer`.
- تخطيط الهاتف له أسلوب مستقل مع تقليل مؤثرات الخلفية المكلفة.
- شاشة الإقلاع تحترم إعداد `prefers-reduced-motion`؛ فلا تظهر لمن يفضّل تقليل الحركة.
- شاشة الإقلاع الكاملة تعمل لمرة واحدة لكل زائر مع إمكانية التخطي، لتبقى التجربة السينمائية دون إبطاء الزيارات المتكررة.
- أضيفت نسخ WebP محسنة داخل `assets/optimized/` للعرض، مع الاحتفاظ بكل أصول PNG الأصلية كمرجع معتمد.
- أضيف زر لغة قمري أعلى الصفحة؛ يحفظ اختيار العربية أو الإنجليزية محلياً في المتصفح.

## تحسينات مقترحة للمرحلة التالية

1. **قياس الاستخدام بموافقة صريحة:** إضافة Microsoft Clarity أو Google Analytics لمعرفة الزيارات والتفاعل. يلزم أولاً تحديد الأداة وسياسة الخصوصية المناسبة.
2. **أداء الصور:** الأصول الحالية أصلية وعالية الجودة وحجمها الكلي يقارب 4.3 MB. يمكن إنشاء نسخ WebP مخصصة للعرض مع الاحتفاظ بالأصل، لكن لا يتم ذلك إلا بعد موافقة لأن الأصول معتمدة بصرياً.
3. **صفحة 404 مخصصة:** تجربة متسقة عند فتح رابط خاطئ داخل GitHub Pages.
4. **محتوى إضافي:** إضافة فقرة قصيرة عن الرؤية أو جهة الإشراف، فقط إذا كانت هناك صياغة رسمية معتمدة.
5. **سهولة الوصول:** مراجعة النصوص البديلة للأصول عند إضافة صور جديدة، مع اختبار دوري لوضع تقليل الحركة.

## قواعد العمل مستقبلاً

- عدّل التصميم من `styles/main.css` فقط، ولا تضف CSS داخل HTML.
- عدّل منطق التفاعل من `scripts/main.js` فقط.
- لا تغيّر أسماء الأصول أو مساراتها إلا مع تحديث جميع الإشارات إليها.
- عند تغيير رابط النشر، حدّث `canonical` و`og:url` و`sitemap.xml` في نفس التعديل.
