# منظومة الصحة الرقمية

بوابة عرض ثابتة لمنصات الخدمات الصحية والرقمية والتوعوية. صُممت كـ«عالم منصات» قابل للنمو، لا كصفحة محصورة في ثلاث خدمات فقط. لا تحتاج إلى خادم أو قاعدة بيانات، ويمكن نشرها مباشرة عبر GitHub Pages.

## البنية

```text
health-showcase/
├── assets/          # الشعارات والصور الأصلية المعتمدة
│   └── optimized/   # نسخ WebP خفيفة للعرض (الأصول الأصلية محفوظة)
├── scripts/main.js  # الساعة والتفاعل الخفيف مع المؤشر
├── styles/main.css  # جميع التنسيقات والحركات
├── index.html       # الصفحة وبيانات المشاركة
├── robots.txt       # إعداد فهرسة محركات البحث
└── sitemap.xml      # عنوان الصفحة للفهرسة
```

## إضافة منصة جديدة

عند إطلاق منصة جديدة، أضفها في موضعين داخل `index.html` للحفاظ على الترتيب البصري:

1. بطاقة داخل قسم العرض الفضائي `stage`، مع رابطها وصورتها أو شعارها المعتمد داخل `assets/`.
2. بطاقة نصية مختصرة داخل قسم `#directory` (خريطة المنظومة).

اجعل صورة المنصة خفيفة وذات حقوق استخدام واضحة، وأبقِ بطاقة «منصة جديدة قريباً» في آخر خريطة المنظومة لتظل البوابة مهيأة للتوسع.

## النشر

ارفع محتويات هذا المجلد إلى جذر مستودع GitHub، ثم فعّل GitHub Pages على فرع النشر. لا تغيّر أسماء الصور داخل `assets/` لأن الصفحة تشير إليها محلياً.

## قبل أي تعديل

- حدّث العناوين والروابط من `index.html` فقط.
- أبقِ صور `assets/` كأصول أصلية غير معدّلة.
- عدّل الألوان والحركة من `styles/main.css` بدلاً من إضافة CSS داخل HTML.
- اختبر الهاتف أولاً؛ التصميم يعتمد نقطة توقف عند 720 بكسل.
- شاشة الإقلاع والصاروخ تعمل لثوانٍ قليلة فقط، وتختفي تلقائياً، كما تتوقف في وضع تقليل الحركة.
- شاشة الإقلاع الكاملة تظهر في أول زيارة فقط؛ في الزيارات التالية تمر سريعاً، ويمكن تخطيها في أي وقت.
- زر القمر `EN` أعلى اليسار يبدّل النصوص الأساسية إلى الإنجليزية ويحفظ اختيار اللغة للزيارة التالية.
- استخدم نسخ `assets/optimized/` للعرض فقط؛ لا تحذف صور PNG الأصلية المعتمدة.
- إن تغيّر رابط GitHub Pages، حدّث `canonical` وبيانات `og:url` و`sitemap.xml` معاً.
